# 化学多模out治理之CoT治理
## 现状
在前期的多模 out 慢思考治理中，直接采用的分离出慢思考数据的正文部分，使用设计的 prompt 结合豆包的能力对正文进行润色，然后进行质检后拼回 CoT部分。
这样做会造成一些问题：
1. 将正文部分直接交由豆包进行润色，任务过于复杂，只能使用具有 smiles 能力且性能较强闭源大模型且良品率低
2. 豆包润色会进行一定的修改加工，无法应用于 CoT 的润色
3. CoT 不经过润色仅润色正文，会影响到多模 out 的触发能力，同时无法将多模 out 模式与模型的推理结合，影响到多模 out 的正确率。
## 解决方案
1. CoT与正文分别润色
2. CoT与正文一致性多模out

> 这里由于正文部分已然完成润色，这里线按照方案一，分别进行润色
